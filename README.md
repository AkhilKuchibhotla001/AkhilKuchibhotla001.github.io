# Personal Developer Portfolio Website

This repository houses the source code for my personal developer portfolio website, hosted live on GitHub Pages at:
👉 **[https://akhilkuchibhotla001.github.io](https://akhilkuchibhotla001.github.io)**

## 🚀 Features & Design Highlights
* **Modern Glassmorphic UI**: Built with a sleek dark slate background, floating accent gradients, blur backdrops, and interactive hover states.
* **Jupyter Notebook-grade Core Projects**: Highlights 6 core academic and research engineering projects with direct links to their source repositories.
* **Interactive Project Filter**: Allows visitors to filter projects dynamically by category (AI/ML, Full-Stack, Cloud/Big Data).
* **Skills Switcher**: Clear categorization of competencies across machine learning, cloud/devops, databases, and core computer science.
* **Connect Utilities**: Interactive contact form validating inquiries, with a seamless fallback to `mailto:` email dispatch.
* **Responsive Layout**: Designed for seamless browsing across all screen sizes (mobile, tablet, desktop).

## 🛠 Tech Stack
* **Structure**: Semantic HTML5
* **Styling**: Modern Vanilla CSS3 (Custom Grid layouts, HSL/HEX variables, transitions, animations)
* **Interactivity**: Vanilla JavaScript (Typing text animation, category filtering, tab toggles, form handler)
* **Icons & Typography**: FontAwesome, Google Fonts (Outfit, Fira Code)
